# MindFlowApp 🧠

Um aplicativo mobile de organização e planejamento para estudos, desenvolvido em **Android Studio** com **Kotlin** e **Jetpack Compose**.

## 📋 Sobre o Projeto

MindFlowApp é uma aplicação Android que ajuda estudantes a organizar suas tarefas, disciplinas e cronogramas de estudo. Desenvolvido como trabalho de conclusão para a disciplina de **Desenvolvimento Mobile**.

## 🎯 Funcionalidades

- 📅 Planejamento e organização de estudos
- 📝 Gerenciamento de tarefas e projetos
- ⏰ Cronograma e lembretes
- 🎨 Interface moderna com Jetpack Compose

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Kotlin
- **Framework UI:** Jetpack Compose
- **Compilação:** Gradle (KTS)
- **Versão do Android:** SDK 24+ (minSdk), SDK 36 (targetSdk)
- **Ícones:** Material Icons Extended
- **Serialização:** Gson
- **Carregamento de Imagens:** Coil
- **Testing:** JUnit, Espresso, AndroidTest
